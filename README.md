# 📖 New Words

A clean and lightweight web application designed to help learn, review, and retain new vocabulary effectively.

---

## ✨ Features

- **Vocabulary Learning**: Look up, add, and practice new words.
- **Minimalist & Fast**: Built as a pure static web app without heavy frameworks.
- **Always Accessible**: Hosted directly via GitHub Pages for easy access across desktop and mobile devices.
